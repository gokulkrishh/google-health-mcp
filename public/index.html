Read-only by design

It only asks Google for read access, so it can never change or delete your data. An access token keeps everyone else out.

Works with any MCP app

Claude on web, desktop and phone, Claude Code, ChatGPT, Grok, and anything that speaks the Model Context Protocol.

Add it to your AI app

Pick your app. Replace YOUR_TOKEN with your access token, and never paste the token into a chat.

  1. Open claude.ai, then Settings → Connectors → Add custom connector.
  2. Name it Google Health and paste your server address.
  3. Set authentication to No sign in.
  4. Under Request headers, add Authorization with the value shown here.
  5. Turn on Google Health from the tools menu in a chat. It also works in the desktop and phone apps.

get_daily_summaryOne day at a glance: steps, distance, calories, Active Zone Minutes, resting heart rate, HRV, sleep and workouts.

Troubleshooting

The common fixes.

"Not signed in"

Use Sign in with Google. You only need it again if Google ends the sign-in.

"Unauthorized" or "credential rejected"

The token in your app is wrong or was changed. Update it in the app's connector settings.

No data for today

Open the Fitbit app so your tracker syncs. Sleep and resting heart rate appear after a night's wear.

Is it up?

/healthz returns ok when the server is running.
