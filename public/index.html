Google Health MCP

A private, read-only MCP server that lets AI apps like Claude, ChatGPT and Grok answer questions about your Fitbit and Pixel Watch data, such as sleep, steps, heart rate and weight.

Unofficial. A community project, not made or supported by Google or Fitbit. It can only read your data, never change it.

What is MCP?

The Model Context Protocol is a standard way for AI apps to use outside tools. Once you add this server to an app, you can ask things like "How did I sleep last night?" or "Show my steps for the last week" and it fetches the answer from your Google Health account.

Your server address

/mcp

Every app also needs your access token (the MCP_HTTP_TOKEN you set in Vercel). Treat it like a password: anyone with it can read your health data. Never paste it into a chat.

Step 1. Connect your Google account (once)

This lets the server read your Fitbit data. You only redo it if Google ends the sign-in.

Step 2. Add it to your AI app

Claude (web, desktop and mobile)

  1. Open claude.ai → Settings → Connectors → Add custom connector.
  2. Name it Google Health and paste the server address above.
  3. Authentication: No sign in.
  4. Under Request headers add Authorization with the value Bearer YOUR_TOKEN (with a space after "Bearer").
  5. In a chat, turn on Google Health from the tools menu.

It then works in the Claude desktop and phone apps too.

Claude Code

Run in your terminal, replacing YOUR_TOKEN:

claude mcp add --transport http -s user google-health /mcp --header "Authorization: Bearer YOUR_TOKEN"

Then check it with claude mcp list.

ChatGPT

  1. Settings → Apps & Connectors → Advanced, turn on Developer mode (paid plans).
  2. Create a connector with authentication No authentication and this URL, replacing YOUR_TOKEN:
/mcp?key=YOUR_TOKEN

Grok and other apps

Grok: grok.com/connectors → New Connector → Custom. Any app that supports remote MCP servers ("Streamable HTTP") works: use the server address with an Authorization: Bearer YOUR_TOKEN header, or the ?key= URL if the app has no header field.

Try asking

  • "How did I do today?"
  • "How did I sleep last night?"
  • "Steps per day for the last 2 weeks, as a table."
  • "Is my resting heart rate going up or down this month?"

Troubleshooting

  • "Not signed in": use the Sign in with Google button above.
  • "Unauthorized" or "credential rejected": the token in your app is wrong or was changed. Update it.
  • No data for today: open the Fitbit app so your tracker syncs. Sleep and resting heart rate appear after a night's wear.
  • Server status: /healthz should say ok.
